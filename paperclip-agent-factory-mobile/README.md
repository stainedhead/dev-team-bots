# Paperclip Agent Factory Mobile

Native iPhone and Android apps for remotely managing one or more [Paperclip](https://docs.paperclip.ing) AI-agent instances through the Paperclip REST API. Shared Kotlin Multiplatform core, SwiftUI and Jetpack Compose UIs.
